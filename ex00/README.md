# ex00 — whatever（関数テンプレート入門）

## 1. この演習でやること

3つの **関数テンプレート** を実装します。どれも「型を問わず使える」のがポイントです。

| 関数 | シグネチャ | 仕様 |
|------|-----------|------|
| `swap` | `void swap(T& a, T& b)` | 2つの値を入れ替える。戻り値なし。 |
| `min`  | `T const& min(T const& a, T const& b)` | 小さい方を返す。**等しければ2番目(`b`)** を返す。 |
| `max`  | `T const& max(T const& a, T const& b)` | 大きい方を返す。**等しければ2番目(`b`)** を返す。 |

- 比較演算子（`<`, `>`）と代入が使える型なら、どんな型でも呼べます
  （`int`, `double`, `char`, `std::string`, ...）。
- 引数 `a` と `b` は **同じ型** どうしであることが前提です。

期待する出力（PDFの指定）:

```
a = 3, b = 2
min( a, b ) = 2
max( a, b ) = 3
c = chaine2, d = chaine1
min( c, d ) = chaine1
max( c, d ) = chaine2
```

## 2. 登場する新しい概念

### 2-1. 関数テンプレート と `template <typename T>`

「型 `T` を後から差し込める設計図」として関数を書きます。

```cpp
template <typename T>        // 「型 T を1つ受け取る設計図」という宣言
void swap(T& a, T& b)        // 本体の中では T を普通の型のように使える
{
	T tmp = a;               // T 型の一時変数
	a = b;
	b = tmp;
}
```

- `template <typename T>` を関数の直前に書くと、その関数はテンプレートになります。
- `T` は仮の型名。`swap(intA, intB)` と呼べば、コンパイラが `T = int` と
  **型推論** し、`swap<int>` を自動生成（インスタンス化）します。

### 2-2. なぜ引数の渡し方を使い分けるのか

```cpp
void swap(T& a, T& b)                 // 非const参照: 中身を書き換えるため
T const& min(T const& a, T const& b)  // const参照: 書き換えないし、コピーも避けたい
```

- `swap` は `a` と `b` を **書き換える** ので、参照 `T&` で受けます。
  値渡し（`T a`）だとコピーが入れ替わるだけで、呼び出し元は変わりません。
- `min` / `max` は引数を **読むだけ** なので `T const&`（const参照）で受けます。
  - `const` を付けることで「中で書き換えない」とコンパイラに約束できます。
  - 参照にすることで、`std::string` のような大きな型でも **コピーが発生しません**。
  - 戻り値も `T const&` にして、返すときのコピーも避けています。

### 2-3. 「等しいときは2番目を返す」ロジック

```cpp
template <typename T>
T const& min(T const& a, T const& b)
{
	if (a < b)        // a が厳密に小さいときだけ a
		return (a);
	return (b);       // それ以外（a > b でも a == b でも）は b
}
```

`a == b` のとき、`a < b` は偽なので `return (b)` に進みます。
よって「等しければ2番目(`b`)」という仕様を満たします。`max` も同様です。
`main.cpp` では、値が同じときに **アドレス比較** で「本当に `b` が返ったか」を
確認しています。

```cpp
int x = 5, y = 5;
// &min(x, y) == &y なら、min は2番目(y)を返している
std::cout << (&::min(x, y) == &y ? "yes" : "no") << std::endl;  // yes
```

### 2-4. なぜ `::swap` のように `::` を付けるのか（重要）

```cpp
::swap(a, b);
```

- `::` を名前の前に付けると **「グローバル名前空間の」** という意味になります。
- C++ の標準ライブラリには `std::swap` / `std::min` / `std::max` が存在します。
- `<string>` などを include すると、**引数依存の名前探索（ADL）** によって
  `std::swap` などが呼び出し候補に入り、自作の `swap` と **どちらを呼ぶか曖昧**
  になってコンパイルエラーになることがあります。
- `::swap(a, b)` と明示すれば「**自分が定義したグローバルの `swap`** を呼べ」と
  はっきり指示でき、衝突を確実に回避できます。

> まとめ: `::` は「グローバルスコープを指定する演算子（scope resolution operator）」。
> 標準ライブラリの同名関数との衝突を避けるために付けています。

## 3. ファイル構成と各ファイルの役割

```
ex00/
├── Makefile        ビルド設定
├── main.cpp        テスト（int / string / double / char、等値ケース）
├── whatever.hpp    swap / min / max の【定義】（テンプレートなのでヘッダに書く）
└── README.md       このファイル
```

### なぜ `whatever.hpp` に実装を書くのか

テンプレートは **使われた型ごとにインスタンス化** されます。
`main.cpp` が `swap(a, b)`（`int`版）を呼ぶとき、コンパイラの目の前に `swap` の
**中身（定義）** が見えていないと `swap<int>` の実体を生成できません。
そのため、定義を `.cpp` に隠さず **ヘッダに書いて include** します
（→ 詳細はモジュール直下の README の「1-5 なぜテンプレートはヘッダに書くのか」）。

## 5. コードの詳細解説

### swap

```cpp
template <typename T>
void swap(T& a, T& b)
{
	T tmp = a;   // a を退避（この時点で a, tmp が同じ値）
	a = b;       // a に b を入れる（a は b の値になった）
	b = tmp;     // b に退避した元の a を入れる
}
```

一時変数 `tmp` を使う、ごく基本的な3手順の入れ替えです。`T&`（非const参照）で
受けているので、呼び出し元の変数そのものが書き換わります。

### min / max

`min` は「`a < b` なら `a`、さもなくば `b`」。
`max` は「`a > b` なら `a`、さもなくば `b`」。
いずれも **比較演算子だけ** に依存しているので、`<` `>` を持つ任意の型で動きます
（`std::string` は辞書順比較が定義済みなので、そのまま使えます）。

## 6. つまずきポイント / 評価で訊かれること（Q&A）

**Q. なぜテンプレートの定義を `.cpp` に分離できないのですか？**
A. テンプレートは「使われた型」ごとにコンパイラがインスタンス化します。
`main.cpp` のコンパイル時に `swap` の定義が見えていないと、`swap<int>` の実体を
生成できず、リンク時に "undefined reference" になります。だから定義はヘッダに置き、
使う側が include します。

**Q. `typename` と `class` の違いは？**
A. `template <typename T>` と `template <class T>` は **完全に同じ意味** です
（テンプレート型パラメータの宣言においては）。好みの問題で、本演習では `typename`
を使っています。

**Q. なぜ `::swap` と書くのですか？ `swap` ではダメ？**
A. `std::swap` などの標準関数と名前が衝突して曖昧になることがあります。
`::` を付けてグローバル名前空間の自作 `swap` を明示することで、衝突を回避します。

**Q. `min`/`max` が引数を `T const&` で受けているのはなぜ？**
A. (1) 中で書き換えないことを保証するため（`const`）、(2) `std::string` のような
大きな型でもコピーを発生させないため（参照）。読み取り専用なら const参照が定石です。

**Q. 等しいときにどちらが返りますか？**
A. 仕様どおり **2番目（`b`）** が返ります。`if (a < b)` / `if (a > b)` が
「厳密に小さい／大きい」場合だけ `a` を返し、等しい場合は `b` に落ちるためです。

**Q. `int` と `double` のように異なる型を渡せますか？**
A. このテンプレートは引数が **同じ型 `T`** であることを前提にしています。
`min(1, 2.0)` のように型が混ざると、`T` を一意に推論できずコンパイルエラーになります
（本演習の要件としては「同じ型どうし」で問題ありません）。
